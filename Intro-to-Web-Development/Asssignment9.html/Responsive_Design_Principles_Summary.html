Responsive Design Principles

Three important concepts

Fluid Layouts

Fluid layouts use flexible sizes so content can adjust to different screen widths. 

width: 90%;

Flexible Media

Images and other media should resize according to the available screen space. 

img {
    max-width: 100%;
}

Breakpoints

Breakpoints allow a layout to change at specific screen widths using media queries. 

@media (max-width: 600px) {
    ...
}
