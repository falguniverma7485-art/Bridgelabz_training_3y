Responsive CSS Cheat Sheet

Quick revision of important concepts

Filters

Key: filter

Example: filter: grayscale(100%);

Media Queries

Key: @media

Example: @media (max-width: 700px)

Responsive Design

Key: Flexible Layout

Webpages adjust according to screen size.

Typography

Key: clamp()

Example: font-size: clamp(1rem, 2vw, 2rem);

Grid

Key: grid-template-columns

Creates flexible rows and columns.

Flexbox

Key: display: flex

Useful for one-dimensional alignment.
